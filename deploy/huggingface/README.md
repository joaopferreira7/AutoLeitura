# AutoLeitura

Leitura automática de medidores de água e energia por visão computacional
(YOLOv8 para o contador + CRNN e YOLOv8 para os dígitos).

Projeto de Visão Computacional, Ciência da Computação, UNISAGRADO.
Código: https://github.com/joaopferreira7/AutoLeitura

Os modelos foram treinados com o dataset UFPR-AMR (Laroca et al., 2019), de uso exclusivamente acadêmico.
Esta demonstração não guarda dados: o banco é apagado sempre que o Space reinicia.
